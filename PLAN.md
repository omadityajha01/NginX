# Plan: NGINX Server Generator (5 inputs → full working server)

## 1. Goal
Build an NGINX server where you only supply **5 inputs**:

1. Domain
2. Listen port(s)
3. Backend IP(s)
4. Backend port(s)
5. Backend protocol

Everything else (load balancing, caching, HTTPS, security, tuning, logging) comes **pre-planned with sensible defaults**.

### Decisions made
| Decision | Choice |
|---|---|
| Runtime | **Docker** (Docker Desktop is installed; native nginx is not) |
| Input style | **Interactive prompts** in the terminal |
| HTTPS | **Self-signed certificate** generated automatically (switch to Let's Encrypt later) |
| Demo backends | **Yes**: 3 demo apps to test load balancing right away |
| Language | Python 3.12, **standard library only** (nothing to install) |

## 3. Inputs: what `setup.py` asks
Every prompt has a default, so pressing **Enter** accepts it.

| # | Prompt | Default | Validation / behavior |
|---|---|---|---|
| 1 | Domain | `localhost` | Used for `server_name` and the certificate SAN |
| 2 | HTTP listen port | `80` | Checks if the port is busy and suggests `8080` |
| 3 | HTTPS listen port | `443` | Checks if the port is busy and suggests `8443` |
| 4 | Backends (`ip:port`, one per line, blank to finish) | 3 demo backends | Checks IP/hostname format and port 1–65535. Rewrites `localhost`/`127.0.0.1` to `host.docker.internal` (inside a container, 127.0.0.1 means the container itself) |
| 5 | Backend protocol | `http` | `http` / `https` / `fastcgi` (PHP-FPM) / `grpc` |

**Flags**
- `--from-file`: regenerate from `nginx-inputs.json` with no prompts
- `--no-start`: generate files only, don't start Docker

**After the prompts, the script:**
1. Writes `nginx-inputs.json`, `nginx/nginx.conf`, `nginx/conf.d/site.conf`, `docker-compose.yml`
2. Creates a self-signed cert (SAN = domain + localhost) using Git for Windows' `openssl`, or falls back to `docker run alpine/openssl`. Existing certs are kept.
3. Runs `docker compose up -d`
4. Runs `docker compose exec nginx nginx -t` to validate the config
5. Prints test URLs and useful commands

Templates are filled with Python's `string.Template`; protocol-specific blocks are chosen in code.

## 4. Pre-planned defaults (what you don't have to decide)

| Area | Default |
|---|---|
| **Load balancing** | `least_conn`; `max_fails=3 fail_timeout=30s` per server; `keepalive 32` connections to upstream |
| **Reverse proxy** | HTTP/1.1 upstream; headers `Host`, `X-Real-IP`, `X-Forwarded-For`, `X-Forwarded-Proto`; timeouts connect 5s / read 60s; `proxy_next_upstream error timeout http_502 http_503` (automatic retry on another backend) |
| **WebSockets** | `map $http_upgrade` → Upgrade supported automatically on all paths |
| **Caching** | 1 GB on-disk `proxy_cache`; caches only when the backend sends `Cache-Control`; bypassed when a `Cookie` or `Authorization` header is present; serves stale content on backend errors; `X-Cache-Status` response header |
| **HTTPS** | HTTP→HTTPS 301 redirect; TLS 1.2 + 1.3; SSL session cache; HTTP/2 on; HSTS **off** for now (unsafe with a self-signed cert; README explains when to enable it) |
| **Security** | `server_tokens off`; `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`; rate limit 10 req/s per IP with burst 20; `client_max_body_size 10m` |
| **Performance** | `worker_processes auto`; `worker_connections 4096`; `sendfile`, `tcp_nopush`; gzip for text/JSON/JS/CSS |
| **Observability** | Access log includes `$request_time`, `$upstream_response_time`, `$upstream_addr`, `$upstream_cache_status`; `/nginx_status` (stub_status, local/Docker network only); `/healthz` returns 200 from NGINX itself |

### Protocol mapping
| Protocol | Generated directive |
|---|---|
| `http` | `proxy_pass http://app_backend;` |
| `https` | `proxy_pass https://app_backend;` + `proxy_ssl_server_name on;` |
| `fastcgi` | `fastcgi_pass app_backend;` + `fastcgi_params` (no proxy cache) |
| `grpc` | `grpc_pass grpc://app_backend;` (uses HTTP/2 on the HTTPS listener) |

## 5. Docker setup (`docker-compose.yml`)
- **nginx** service
  - Image: `nginx:1.27-alpine` (pinned version)
  - Ports: `<http_port>:80`, `<https_port>:443`
  - Mounts: `nginx/nginx.conf`, `nginx/conf.d/`, `certs/`, plus a named volume for the cache
  - `extra_hosts: host.docker.internal:host-gateway` (to reach apps on your PC)
  - `restart: unless-stopped`
- **Demo backends** (demo mode only): `app1`, `app2`, `app3` using `traefik/whoami:v1.10`. Each replies with its own hostname, which shows which server handled the request. Backends are set to `app1:80`, `app2:80`, `app3:80`.

## 6. Request flow
```
Browser ──HTTP :80──► NGINX ──301──► HTTPS :443
                        │
                        ├─ /healthz       → 200 (NGINX itself)
                        ├─ /nginx_status  → stats (local only)
                        └─ /*  → rate limit → cache? ──hit──► response
                                               │ miss
                                               ▼
                                   upstream app_backend (least_conn)
                                   ├── backend 1
                                   ├── backend 2
                                   └── backend 3   (failed → retried on next)
```

## 7. Verification checklist
| # | Test | Expected result |
|---|---|---|
| 1 | `python setup.py`, Enter for all defaults | Files generated, containers start, `nginx -t` reports **syntax is ok** |
| 2 | `curl -I http://localhost` | `301` redirect to https |
| 3 | `curl -k https://localhost` × 6 | `Hostname:` cycles across app1/app2/app3 → **load balancing works** |
| 4 | `docker compose stop app2`, curl again | Still succeeds, only app1/app3 respond → **failover works** |
| 5 | `curl -k https://localhost/healthz` | `200` |
| 6 | `curl -k https://localhost/nginx_status` | Connection counters |
| 7 | `docker compose logs nginx` | Log lines show upstream address and timings |
| 8 | Edit `nginx-inputs.json` → `python setup.py --from-file` → `docker compose exec nginx nginx -s reload` | Change applied with no downtime |
| 9 | Run `python -m http.server 9000` on the PC, enter backend `127.0.0.1:9000` | Rewritten to `host.docker.internal:9000`; `curl -k https://localhost` shows the directory listing |
